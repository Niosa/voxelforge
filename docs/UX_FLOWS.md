# UX Flows

## Draw continent (Phase 3)
1. Tap Draw
2. Tap 3+ points on globe
3. Tap Close (or double-tap)
4. Inspector focuses name field
5. Enter name → entity commits via `AddEntityCommand`

## Edit
1. Select polygon → Edit
2. Drag vertices; midpoints insert
3. Done returns to Select

## Search (Phase 5)
1. Type in top bar
2. Arrow keys move result
3. Enter flies camera + selects
